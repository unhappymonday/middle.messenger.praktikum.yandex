# Messenger

Учебный проект мессенджера в рамках курса Яндекс Практикума. Приложение собрано на TypeScript и Handlebars, сборка выполняется через Vite, стили написаны на SCSS.

## Страницы

- авторизация и регистрация;
- список чатов и переписка с группировкой сообщений по датам;
- профиль, изменение данных и пароля;
- страницы ошибок 404 и 500.

## Стек

- TypeScript
- Handlebars
- Vite
- SCSS

## Запуск

Установите зависимости:

```bash
npm install
```

Запустите проект в режиме разработки (по умолчанию http://localhost:3000):

```bash
npm run dev
```

## Сборка

Проверка типов и production-сборка в папку `dist`:

```bash
npm run build
```

Локальный просмотр собранной версии:

```bash
npm run preview
```
